# Frases da Tela de Carregamento — Kurupira

> Inspiradas no **Kerbal Space Program** e no **Manual de Sobrevivência do Instalador Solar**.
> O humor nasce da **cumplicidade com o engenheiro**: no papel tudo é perfeito, mas na hora do "vâmo ver", o caos tenta dar as caras.
> Tom: técnico, ácido, situacional. Nunca genérico. Nunca referência de universo externo.

---

## 📐 Padrão Editorial — O que define uma boa frase

Uma frase aprovada segue pelo menos **um** desses padrões:

| Padrão | Exemplo |
|---|---|
| **Ação técnica (consequência cômica)** | `Validando coordenadas GPS (não queremos painéis no oceano)...` |
| **Situação real da obra, exagerada** | `Verificando se o estagiário apertou os conectores MC4...` |
| **Burocracia ácida** | `Verificando se o parecer de acesso chegou (spoiler: não chegou)...` |
| **Absurdo coerente com o domínio solar** | `Expulsando nuvens passageiras com pensamento positivo...` |

❌ **Não aprovado:** referências externas (Pokémon, etc.), impossibilidades sem graça, frases que servem para qualquer software.

## 📋 Notas de Implementação

**Contexto de uso:** Tela de carregamento de projetos, simulações de geração, exportação de proposta, cálculo de arranjo.

**Seleção por contexto:**

| Evento | Categoria prioritária |
|---|---|
| Cold start / login | 🔧 Manual do Instalador |
| Carregamento de projeto | 🛠️ Engenharia |
| Simulação de irradiância | 🛠️ Engenharia + 💻 SaaS |
| Exportação de proposta | 🛠️ Engenharia (ROI/financeiro) |
| Qualquer contexto | 🪐 Easter Egg com p=0.05 |

**Regras de exibição:**
- Duração mínima: **1,5s** para ser legível. Absoluto mínimo: 800ms.
- Sem repetição nas últimas **5** exibições.
- Easter eggs: probabilidade de **~5%** independente do contexto.
- Frases em inglês: usar apenas se `locale !== 'pt-BR'` (roadmap).

**Fonte de inspiração:** KSP loading tips, estilo Basecamp / Linear "witty copy", Manual de Sobrevivência do Instalador Solar.
